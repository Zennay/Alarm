# Wear OS hardwarecontrole

Versie 0.2.0: **opladen stopt een actief trilalarm**; er zijn geen NFC, stappen, lichten, telefoon of webhooks meer. Details en ADB-instructies: [CHARGING-TEST.md](CHARGING-TEST.md).

1. Met geen actief alarm: test 'Controleer oplader', eerst los van de lader, dan op de lader.
2. Start een testalarm, houd oplader bij de hand. Het horloge moet op zijn eigen lader opladen om trillen te stoppen.
3. Test daarna vaste wektijd en slim wekvenster met display uit.
4. Gebruik reservewekker tot de volledige nachtelijke praktijktest slaagt.
